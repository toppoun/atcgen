# atcgen

AtCoder の Stress Test 用に、入力形式を表す DSL と seed からテストケースを 1 件生成する Rust CLI です。

## 実行例

リポジトリのルートから実行します。

```sh
cargo run --quiet -- generate sample.gen --seed 42
```

下記の DSL を `sample.gen` に記述した場合の出力です。

```text
4 4
8 -4 -3 -7 -9 -14 -6 16 -14 -12 -8 -12 16 -11 7 -7
2 71 92 9
```

ビルド済みの CLI は `atcgen generate sample.gen --seed 42` で実行できます。`--seed` には符号なし 64 ビット整数を指定します。成功時の標準出力は生成した入力のみです。エラーは標準エラー出力に出し、非ゼロで終了します。DSL エラーにはファイル名、行番号、列番号を表示します。

## DSL

```text
input {
    N M
    A[1..(N*M)]
    B[1..M]
}

constraints {
    N in 1..10
    M in 1..N
    A[*] in -(N*M)..(N*M)
    B[*] in -100..100
}
```

- UTF-8 のファイルで `input {`、`constraints {` の順に記述します。ブロックの開始と終了はそれぞれ独立した行に記述します。空行、字下げ、LF と CRLF を使用できます。
- 変数名は `[A-Za-z_][A-Za-z0-9_]*` で、大文字と小文字を区別します。各変数を一度ずつ宣言します。
- `input` の宣言行ごとに 1 行を出力します。同じ行の宣言を空白で区切ります。`N` は整数を 1 個生成し、`A[1..(N*M)]` は `N*M` 個の整数を生成します。配列の添字は `1` から始まります。各行の整数は半角スペース 1 個で区切り、最終行も LF で終わります。
- `constraints` は 1 行に 1 件です。すべての変数について範囲を一度ずつ指定します。スカラーは `N in 1..10`、配列は `A[*] in 1..100` のように記述します。`..` は両端を含みます。
- 生成順は `input` の上から下、同じ行では左から右です。各変数の生成直前に範囲の下端と上端を評価します。配列の場合は長さも評価し、各要素を同じ範囲から生成します。制約の記述順は自由です。

## 整数式

配列長と制約範囲の上下限に整数式を指定できます。整数リテラルは十進表記の符号付き 64 ビット整数（`i64`）です。変数参照には、生成順で値が確定したスカラーだけを使えます。未定義変数、前方参照、自己参照、配列の参照はエラーになります。

| 優先順位（高い順） | 記法 | 意味 |
| --- | --- | --- |
| 1 | `(A+B)` | 括弧内をひとまとまりとして扱う |
| 2 | `-A`、`+A` | 符号反転、値をそのまま返す |
| 3 | `A*B`、`A/B`、`A%B` | 乗算、整数除算、剰余 |
| 4 | `A+B`、`A-B` | 加算、減算 |

同じ優先順位の二項演算子は左結合です。`20-6-3` は `(20-6)-3` と同じです。除算はゼロ方向に切り捨て、剰余は Rust と同じ規則に従います。たとえば `-7/3` は `-2`、`-7%3` は `-1` です。括弧と単項演算子の入れ子は合わせて 128 段までです。負の整数リテラルの符号はこの段数から除きます。

括弧の不一致や未対応の演算子は構文エラーです。ゼロによる除算・剰余、途中の計算を含む整数オーバーフロー、逆転した範囲、0 以下の配列長もエラーになります。`i64` の最小値を `-1` で除算する場合と剰余を取る場合も、Rust と同様にオーバーフローとして扱います。算術エラーは式と該当する演算子の位置を表示します。生成途中でエラーになった場合は標準出力が空のまま終了します。

## 乱数と上限

SplitMix64 の初期状態に `seed` をそのまま設定します。各整数を生成するたびに 64 ビットの乱数を取得します。範囲に含まれる整数の個数を `w` とし、乱数が `2^64 mod w` 未満なら取り直して、`下端 + 乱数 mod w` を採用します。`i64` の全範囲を指定した場合は乱数をそのまま下端からのオフセットに使います。この手順で同じ DSL と seed から同じバイト列を生成します。

1 ケースの上限は整数 1,000,000 個、出力 8 MiB です。出力サイズには空白と改行を含みます。上限を超えた場合は生成結果を出力せずエラーを返します。
