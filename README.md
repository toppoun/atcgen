# atcgen

AtCoder のストレステスト用に、DSL と seed からテストケースを 1 件生成する Rust CLI です。

## 実行例

リポジトリのルートから実行します。ビルド済みの CLI では `atcgen generate sample.gen --seed 42` を実行します。

```sh
cargo run --quiet -- generate sample.gen --seed 42
```

`sample.gen` の内容です。

```text
generate {
    N in 2..=10
    A[N]
    B[N]

    for i in 1..=N {
        A[i] in 1..=99
        B[i] in (A[i]+1)..=100
    }
}

input {
    N
    for i in 1..=N {
        A[i] B[i]
    }
}
```

seed 42 では次のように出力します。

```text
3
83 90
46 99
43 72
```

`input` を次のように書き換えると、同じ値を配列ごとに 1 行で出力します。

```text
input {
    N
    A
    B
}
```

```text
3
83 46 43
90 99 72
```

## 生成と出力

- UTF-8 のファイルに `generate` と `input` をこの順で 1 ブロックずつ記述します。開始行は `{` で終え、`}` は独立した行に置きます。ただし `else` の開始は `} else {` と同じ行に書きます。LF と CRLF、ASCII のスペースとタブを使用できます。空ブロックも有効です。
- `generate` は上から順に実行します。`N in 2..=10` はスカラーを生成し、`A[N]` は長さ `N` の配列を宣言します。要素は `A[i] in 1..=99` のように個別に初期化します。添字は 1 始まりです。
- `generate` の `for` / `if` 本体では宣言済み配列の要素を初期化できます。宣言はトップレベルに置きます。サンプルの `B[i]` は同じ反復で生成した `A[i]` を参照します。前の反復で初期化した要素も参照できます。未初期化要素の読み取り、境界外アクセス、二重初期化はエラーです。
- `input` の `N` はスカラー、`A[i]` は配列の 1 要素、`A` は配列全体を添字順に出力します。1 行に複数の参照を置けます。同じ値を繰り返し参照したり、出力順を変えたりしても、生成結果は同じです。`row` の外の空行はそのまま出力されます。整数間は ASCII スペース 1 個で、各行末は LF です。
- `for` は進入時に範囲を 1 回評価し、下限から昇順に反復します。内側のループは範囲や添字に外側のループ変数を使えます。生成変数や有効な外側のループ変数との名前衝突、およびループ変数の直接出力はエラーです。兄弟ループでは同じ名前を再利用できます。

### ネストした `for` と `row`

下三角行列では、`generate` の内側の反復で一次元配列の各要素を初期化し、`input` の `row` で 1 行分をまとめます。例えば `N=3` の場合、ヘッダーに続く 3 行の幅はそれぞれ 1、2、3 です。

```text
generate {
    N in 1..=100
    A[N*(N+1)/2]
    for i in 1..=N {
        for j in 1..=i {
            A[i*(i-1)/2+j] in 1..=N
        }
    }
}

input {
    N
    for i in 1..=N {
        row {
            for j in 1..=i {
                A[i*(i-1)/2+j]
            }
        }
    }
}
```

`row` 内の参照列は同じ行に追加され、ソース上の空行は読み飛ばされます。値が 0 個の `row` も LF 1 個を出力します。

### 整数の `if` / `else`

条件は整数式どうしの比較を 1 個書きます。`== != < <= > >=` に対応し、`else` は省略できます。`if` はネストでき、`for` とも組み合わせられます。次の例では種別 1 だけ値を 2 個生成し、ほかの種別は値を 1 個生成します。

```text
generate {
    Q in 1..=8
    Kind[Q]
    U[Q]
    V[Q]
    for i in 1..=Q {
        Kind[i] in 1..=3
        if Kind[i] == 1 {
            U[i] in 1..=99
            V[i] in 1..=99
        } else {
            V[i] in 1..=99
        }
    }
}
input {
    Q
    for i in 1..=Q {
        row {
            Kind[i]
            if Kind[i] == 1 {
                U[i]
            }
            V[i]
        }
    }
}
```

`row` 内の分岐は現在の行に値を追加し、改行を増やしません。通常の `input` 内では選んだ分岐の行だけを出力します。未選択の分岐も名前と型を検査しますが、実行時の式評価と乱数消費は行いません。未使用の `U[i]` は未初期化のままで構いません。生成側と出力側の条件はそれぞれ記述して評価します。`if` / `else` という名前の変数も従来どおり使えます。論理演算、連鎖比較、真偽値変数は扱いません。

### ASCII 文字列とグリッド

`S : string[L]` は固定長文字列、`G[H] : string[W]` は共通幅の文字列配列を宣言します。宣言はトップレベルに置き、セルごとに1回だけ初期化します。次の例は文字列を1行、グリッドを行ごとに出力します。

```text
generate {
    S : string[3]
    S[1] = 'a'
    S[2] = S[1]
    S[3] in "bc"
    H in 1..=10
    W in 1..=10
    G[H] : string[W]
    for i in 1..=H {
        for j in 1..=W {
            if i == 1 {
                G[i][j] = '.'
            } else {
                G[i][j] in ".#"
            }
        }
    }
}
input {
    S
    H W
    for i in 1..=H {
        G[i]
    }
}
```

`S` と `G[i]` は文字を連結した1トークン、`S[j]` と `G[i][j]` は1文字のトークンです。`G` は全行をスペース区切りで同じ行に展開します。通常行でも `row` 内でも整数・文字・文字列を混在できます。文字比較は `if S[1] == 'a' {` のように `==` と `!=` に対応します。

文字は非空白・非制御の ASCII に限定し、引用符とバックスラッシュはエスケープできます。候補集合は非空で重複なし。`in "abc"` は1文字でも乱数を消費し、`=` は消費しません。未初期化セルの参照・文字列出力、二重初期化、文字と整数の混在演算はエラーです。

[ABC400-D の生成器](corpus/atcoder/abc400/d/generator.gen) は異なる始点と終点を道にし、ほかのセルを抽選します。公式最大の1000×1000にも対応します。

## 範囲と整数式

`a..b` は上限を含まず、`a..=b` は含みます。空の範囲では `for` は 0 回反復し、値を生成する操作はエラーになります。

配列長、添字、生成範囲、ループ範囲、比較の左右には符号付き 64 ビット整数式を指定できます。生成済みスカラー、初期化済みの配列要素、スコープ内のループ変数を使用できます。演算子の優先順位は括弧、単項 `+ -`、二項 `* / %`、二項 `+ -` の順です。同じ優先順位の二項演算は左結合です。除算はゼロ方向に丸め、剰余は被除数と同符号になります。整数オーバーフローとゼロ除算・ゼロ剰余はエラーです。

## 再現性と上限

`--seed` には符号なし 64 ビット整数を指定します。整数と文字の `in` 初期化で、実行順に SplitMix64 から棄却抽選します。文字の固定初期化 `=` は乱数を消費しません。候補が 1 個でも乱数を 1 語消費します。同じバージョン、DSL、seed で生成した出力はバイト単位で一致します。

| 対象 | 上限 |
| --- | ---: |
| 1 配列の長さ | 1,000,000 |
| 1 ケースの全配列の宣言要素数 | 1,000,000 |
| 1 ケースの生成整数数 | 1,000,000 |
| 文字列の長さ・グリッドの個数×幅・ケースの全文字セル合計 | 各 1,000,000 |
| 1 ケースの出力トークン数（整数・文字・文字列の合計） | 1,000,000 |
| 1 ケースの出力サイズ（区切りと LF を含む） | 8 MiB |
| `for` への進入 1 回あたりの反復回数 | 1,000,000 |
| ネストした `for`、`row`、`if` のいずれかを含む `generate` / `input` の累積実行量 | 各ブロック 10,000,000 単位 |
| `for`、`if`、`row` を合わせた制御ブロックの深さ | 32 段 |
| 式と添字の入れ子 | 128 段 |

CLI はケース全体の検証と整形が成功してから標準出力に書き込みます。DSL のエラー時は標準出力が空で、標準エラー出力に `<file>:<line>:<column>: <message>` を出し、終了コードは 1 になります。行と列は 1 起点で、列は UTF-8 のバイト単位です。

## Phase 3 からの移行

旧形式の `input` と `constraints` は構文エラーになります。生成範囲は `generate` の各スカラー生成・要素初期化へ移します。旧形式の配列出力 `A[N]` は、新形式の `generate` で配列を宣言して各要素を初期化し、`input` で `A` と書きます。新形式の `input` における `A[N]` は添字 `N` の 1 要素を指します。

一括初期化、Unicode・可変長文字列・文字列演算、グラフ専用構文、特殊な制約、問題文の自動解析、`atc-rs` との統合は対象外です。詳細は言語仕様を参照してください。 [DSL 言語仕様](docs/DSL_SPEC.md)
